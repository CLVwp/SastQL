# SastQL native binary

Platform-specific binary for [SastQL](https://github.com/CLVwp/SastQL), the SAST linter for SQL (PostgreSQL & SQLite). Installed automatically as an `optionalDependency` of `@clv.wp/sastql` — do not install this package directly.
